### **WCF Application with Service-Oriented Architecture (SOA) in .NET Framework**

Windows Communication Foundation (**WCF**) is a framework in .NET for building **Service-Oriented Architecture (SOA)** applications. WCF allows services to communicate using different protocols such as **HTTP, TCP, Named Pipes, and MSMQ**.

In **SOA**, applications are structured as independent services that interact through well-defined contracts, promoting reusability, scalability, and maintainability.

---

## **1. Steps to Create a WCF Application with SOA**

We will build a **WCF service for Order Management**, which follows **SOA principles** and exposes an interface for client applications.

---

## **Step 1: Create a WCF Service Application**

1. Open **Visual Studio** and create a new project:
    
    - Select **"WCF Service Application"** from the **New Project** window.
    - Name it `OrderServiceWCF`.
2. This creates a basic WCF project with:
    
    - **IService1.cs** (Service Contract)
    - **Service1.svc.cs** (Service Implementation)
    - **Web.config** (Service Configuration)

---

## **Step 2: Define the Service Contract (Interface)**

A **Service Contract** defines the operations exposed by the service.

Modify `IService1.cs`:

```csharp
using System.Collections.Generic;
using System.ServiceModel;

namespace OrderServiceWCF
{
    [ServiceContract]
    public interface IOrderService
    {
        [OperationContract]
        List<Order> GetOrders();

        [OperationContract]
        Order GetOrderById(int id);

        [OperationContract]
        void CreateOrder(Order order);
    }

    [DataContract]
    public class Order
    {
        [DataMember]
        public int Id { get; set; }

        [DataMember]
        public string ProductName { get; set; }

        [DataMember]
        public int Quantity { get; set; }

        [DataMember]
        public decimal Price { get; set; }
    }
}
```

- **[ServiceContract]**: Declares an interface as a WCF service.
- **[OperationContract]**: Marks methods that are exposed to clients.
- **[DataContract]**: Defines a serializable data object.
- **[DataMember]**: Specifies properties to be serialized.

---

## **Step 3: Implement the Service Logic**

Modify `Service1.svc.cs` to implement the `IOrderService` interface:

```csharp
using System.Collections.Generic;
using System.Linq;

namespace OrderServiceWCF
{
    public class OrderService : IOrderService
    {
        private static List<Order> _orders = new List<Order>
        {
            new Order { Id = 1, ProductName = "Laptop", Quantity = 1, Price = 1000 },
            new Order { Id = 2, ProductName = "Phone", Quantity = 2, Price = 500 }
        };

        public List<Order> GetOrders()
        {
            return _orders;
        }

        public Order GetOrderById(int id)
        {
            return _orders.FirstOrDefault(o => o.Id == id);
        }

        public void CreateOrder(Order order)
        {
            order.Id = _orders.Max(o => o.Id) + 1;
            _orders.Add(order);
        }
    }
}
```

---

## **Step 4: Configure the Service in Web.config**

Modify the `Web.config` file to configure the WCF service:

```xml
<system.serviceModel>
  <services>
    <service name="OrderServiceWCF.OrderService">
      <endpoint address="" binding="basicHttpBinding" contract="OrderServiceWCF.IOrderService"/>
      <host>
        <baseAddresses>
          <add baseAddress="http://localhost:8080/OrderService"/>
        </baseAddresses>
      </host>
    </service>
  </services>

  <behaviors>
    <serviceBehaviors>
      <behavior>
        <serviceMetadata httpGetEnabled="true"/>
        <serviceDebug includeExceptionDetailInFaults="true"/>
      </behavior>
    </serviceBehaviors>
  </behaviors>

  <bindings>
    <basicHttpBinding>
      <binding name="basicHttp"/>
    </basicHttpBinding>
  </bindings>
</system.serviceModel>
```

- **basicHttpBinding**: Enables HTTP communication.
- **baseAddresses**: Defines where the service is hosted.
- **serviceMetadata**: Allows WCF clients to discover the service.

---

## **Step 5: Host the WCF Service**

### **Method 1: Self-Hosting Using a Console Application**

Create a **new Console Application** and add a reference to `OrderServiceWCF.dll`.

Modify `Program.cs`:

```csharp
using System;
using System.ServiceModel;

namespace WCFHost
{
    class Program
    {
        static void Main(string[] args)
        {
            using (ServiceHost host = new ServiceHost(typeof(OrderServiceWCF.OrderService),
                new Uri("http://localhost:8080/OrderService")))
            {
                host.Open();
                Console.WriteLine("Order Service is running...");
                Console.WriteLine("Press any key to exit.");
                Console.ReadKey();
            }
        }
    }
}
```

Run the application, and the service will be hosted at `http://localhost:8080/OrderService`.

---

## **Step 6: Create a WCF Client**

### **Method 1: Consume the WCF Service in a Console Application**

Create a **new Console Application** and add a **Service Reference**:

1. Right-click **References** > **Add Service Reference**.
2. Enter `http://localhost:8080/OrderService?wsdl` and click **Go**.
3. Name the namespace `OrderServiceClient`.

Modify `Program.cs`:

```csharp
using System;
using OrderServiceClient;

namespace WCFClient
{
    class Program
    {
        static void Main(string[] args)
        {
            IOrderService client = new OrderServiceClient();

            var orders = client.GetOrders();
            foreach (var order in orders)
            {
                Console.WriteLine($"Order ID: {order.Id}, Product: {order.ProductName}");
            }

            Console.ReadKey();
        }
    }
}
```

## **Step 7: Deploy the WCF Service**

You can deploy the **WCF service** using:

- **IIS (Internet Information Services)**
- **Windows Service**
- **Azure App Services**

For **IIS Deployment**:

4. **Publish** the WCF service as a Web Deploy Package.
5. **Host it in IIS** and configure the **application pool**.
6. **Update the client** to use the IIS-hosted URL.

---

## **Step 8: Secure the WCF Service**

- Use **Message Security** (Username/Password authentication).
- Use **Transport Security** (SSL/TLS).
- Implement **Token-based Authentication** (JWT or OAuth).

Example: Enable **Transport Security** in `Web.config`:

```xml
<bindings>
  <basicHttpBinding>
    <binding name="SecureBinding">
      <security mode="Transport">
        <transport clientCredentialType="None"/>
      </security>
    </binding>
  </basicHttpBinding>
</bindings>
```

---

## **Summary**

- **SOA in WCF** organizes functionality into independent services.
- **Service Contracts** define what the service exposes.
- **WCF Configuration** allows flexible communication over HTTP, TCP, MSMQ.
- **Service Hosting** can be done using **self-hosting, IIS, Windows Service, or Azure**.
- **WCF Client** consumes the service through a proxy.
